Featured Vrbo property photos
=============================

Drop ONE hero photo per destination here, named exactly as below (lowercase,
.jpg). The Book page "Our pick" stay card uses it automatically. Until a file
exists, the card falls back to that trip's golf photo.

Recommended: ~1200x800 (3:2), under ~300 KB.

Filenames (one per destination that has a featured Vrbo property) — all added:
  las-vegas.jpg
  palm-springs.jpg
  san-diego.jpg
  pinehurst.jpg
  boyne.jpg
  myrtle-beach.jpg
  hilton-head-island.jpg
  scottsdale.jpg
  naples.jpg

Orlando and Charleston have NO featured-stay photo on purpose — their Vrbo
affiliate links are area-wide (not a single property), so they show only the
general "More rentals on Vrbo" button, no "Our pick" card.

Tip: as the Vrbo affiliate you can use the listing's own photos — grab the
main image from each property page.
